# Predicting U.S. Congressional District Poverty Status
## From 2019-2021, Using Socioeconomic Indicators and Random Forest
### cs474 Capstone Project: Jonas Nebele & Greeshma Yadlapalli

Poverty status is one of the largest indicators of a community's economic health because it affects policy and resource allocation. This research proposal examines how accurately a Random Forest classifier can classify U.S. congressional districts as above or below the poverty line using district-level U.S. Census data from 2019 to 2021. Each district will be assigned a binary label based on the poverty benchmark from 2020 and 2021. The model will be trained on socioeconomic predictors from education, industry, and finance data, including educational attainment, industry distribution, and income-related measures. Random Forest is best for tabular census data because it captures non-linear relationships while reducing overfitting and instability of a single decision tree. Performance will be evaluated using stratified K-fold cross-validation, with accuracy, precision, recall, F1 score, and ROC-AUC to check for any class imbalance between districts above and below the threshold. Random Forest's built-in feature importance measures will be used to identify which socioeconomic variables contribute most to classification. We expect the results to show how reliably district poverty status can be predicted from education, industry, and financial indicators. Using these results we hope to understand more about the different factors contributing to poverty and how they persist.
